# REST API Endpoint Documentation

## 1. Domain Catalog Endpoints

### `GET /api/products`
Returns active product catalog with category titles, unit costs, selling prices, and lead times.

### `GET /api/warehouses`
Returns list of registered distribution centers, codes, locations, and capacity thresholds.

### `GET /api/inventory?warehouse_id={optional}`
Returns current stock levels, allocated stock, available stock, unit costs, and total inventory value.

## 2. AI/ML Analytical Endpoints

### `GET /api/forecast/{product_id}?horizon_days=30`
Generates statistical time-series demand forecast for a product over 7, 14, or 30 days.
**Response**: Total demand, 95% confidence intervals, MAE, RMSE, daily predicted points.

### `GET /api/inventory-risk?risk_level={CRITICAL|HIGH|MEDIUM|LOW}`
Returns risk classification matrix for all product/warehouse combinations with explanatory rationale.

### `GET /api/inventory-recommendations`
Generates automated replenishment orders, recommended reorder quantities, target supplier, and action items.

### `GET /api/control-tower`
Aggregates executive KPIs: Total Inventory Value, Critical Risk Counts, High Risk Counts, Open POs, 30-Day Sales.

## 3. GenAI & ReAct Agent Chat

### `POST /api/ai/chat`
**Body**: `{"message": "Which products are at risk of stockout?"}`
**Response**: Evidence-backed natural language response generated by Claude/ReAct Agent using MCP tools.

## 4. Ingestion & BI Adapters

### `POST /api/ingest/csv`
Uploads CSV file for automated validation and stock ingestion.

### `GET /api/bi/export` & `GET /api/bi/export/csv`
Exports operational supply chain datasets formatted for PowerBI and Tableau.
